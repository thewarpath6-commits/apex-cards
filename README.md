# APEX — Motor League

A mobile-first browser prototype for a collectible car-card game.

## Play locally
Open `index.html` in a modern browser. Progress is saved in localStorage.

## Publish
GitHub Actions workflow `.github/workflows/pages.yml` deploys the site to GitHub Pages on every push to `main`. If the first deployment does not start, enable Pages in **Settings → Pages → Build and deployment → GitHub Actions**.

## Current prototype
- Garage and rarity filters
- Starter pack opening
- Five-car team builder with 100 RQ cap
- Five-round race against a simple CPU opponent
- Local save in the browser

This is a prototype: no accounts, server-side storage, matchmaking, or real PvP yet.
